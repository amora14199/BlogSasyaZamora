Deskripsi Project
Project ini adalah website portofolio yang saya buat sebagai tugas Ujian Akhir pada mata kuliah Desain Web. 
Website ini berisi informasi tentang diri saya, riwayat pendidikan, keahlian, portofolio project, serta 
halaman kontak yang dilengkapi validasi form. Tampilan web dibuat sederhana, rapi, dan tetap estetik.


Fitur Utama
1. Halaman Home
   - Foto profil, nama, dan sedikit deskripsi tentang saya.
   - Tombol langsung menuju portfolio dan contact.
   - Slider (carousel) berisi 3 gambar dengan teks tambahan:
        * Welcome to my web
        * Lihatlah project saya
        * Jika ingin bekerja sama langsung contact saya!
   - Bagian “Keahlian Saya” dengan 3 fitur utama.

2. Halaman About
   - Data diri singkat dan cerita perjalanan belajar.
   - Riwayat pendidikan:
        * SD 01 Tanjung Paku
        * SMP Negeri 02 Kota Solok
        * SMA Negeri 2 Sumatera Barat
        * S1 Informatika Universitas Andalas
   - Hardskill:
        * UI/UX Basic
        * Canva Editing
        * Java Dasar
        * Public Speaking
        * Teamwork
        * Time Management
   - Hobi/Minat:
        * Traveling, Musik, Fotografi, Editing

3. Halaman Portfolio
   - Menampilkan 6 project dengan kategori Web, App, dan Design.
   - Ada fitur filter berdasarkan kategori.
   - Setiap project memiliki modal berisi foto + deskripsi.

4. Halaman Contact
   - Form kontak dengan validasi (Bootstrap Validation).
   - Tombol submit hanya aktif kalau form sudah lengkap.
   - Setelah submit muncul alert “Your message has been sent successfully!”.
   - Terdapat informasi kontak seperti email, alamat, nomor HP, dan Instagram.


Teknologi yang Digunakan
- HTML
- CSS (custom + Bootstrap)
- Bootstrap 5.3 (navbar, slider, modal, card, form)
- JavaScript (validasi form dan filter portfolio)


Cara Menjalankan
1. Simpan semua file dalam satu folder:
   - index.html
   - about.html
   - portfolio.html
   - contact.html
   - style.css
   - folder images (isi foto profil, slider, icon, dan project)

2. Pastikan nama file gambar sudah sesuai dengan yang dipakai di dalam kode
   seperti: slide1.jpg, slide2.jpg, slide3.jpg, home1.jpg, project1.jpg, dll.

3. Jalankan dengan membuka file index.html di browser.
